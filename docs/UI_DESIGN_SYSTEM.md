# WavePlug UI 规范 — v0 草案

> 状态（2026-11-04）：token 已接入 `styles.css`（旧变量名保留为别名，外观不变），组件还没迁移。功能开发期间先按这里的规则写新代码；功能基本完成后再统一迁移（见第 7 节）。第 8 节的三项决策已经定了。
> Token 定义在 [`plugin/styles.css`](../plugin/styles.css) 开头的 `:root`（dev 加载器只读这一个 CSS 文件）。改规范时两边一起改。

## 1. 原则

1. **像 PS 自带的面板**：克制、紧凑、原生感。不追求个性化视觉，不用渐变、玻璃、大圆角、阴影。
2. **无感**：不跳动、不闪。悬停、加载、展开时布局尺寸不变。
3. **可读**：文字高对比，最小 11px（PS 常用中灰主题）。
4. **说明用悬停提示**（`src/ui/tooltip.ts`），不用「?」弹窗，不加固定说明行。
5. **一种东西只有一种样子**：同一功能的控件，在两个面板里尺寸、颜色和状态都一致。

## 2. Token

完整值见 `styles.css` 开头。组件里**只用 token，不写数字和颜色**。确实需要新值时，先在这里加 token。

| 类别 | Token | 用途 |
|---|---|---|
| 字号 | `--fs-s` 11 / `--fs` 12 / `--fs-l` 13 | 次要信息 / 正文和控件 / 分区标题 |
| 间距 | `--sp-1`…`--sp-6` = 2 / 4 / 6 / 8 / 12 / 16 | 不用 3、5、7、9、10 |
| 控件高 | `--h-xs` 18 / `--h-s` 24 / `--h-m` 26 / `--h-l` 30 / `--h-count` 34 / `--h-drag` 36 | 标签 / 紧凑控件 / 默认控件 / 主按钮 / 生图数量行 / 图层拖拽虚影 |
| 图标 | `--ic-s` 12 / `--ic-m` 16 | 行内 / 按钮和工具栏 |
| 圆角 | `--r-s` 2 / `--r` 4 / `--r-pill` 13 | 缩略图、复选框 / 控件、卡片 / 胶囊 |
| 文字色 | `--c-text` / `--c-text-2` / `--c-text-3` | 正文 / 次要 / 弱提示（不可用于需要阅读的文字） |
| 面 | `--c-bg` / `--c-surface` / `--c-field` | 面板 / 分区 / 控件底 |
| 线 | `--c-line` / `--c-line-soft` / `--c-line-row` | 控件描边 / 分区线 / 列表行线 |
| 强调 | `--c-accent` / `-hi` / `-ink` / `-wash` / `-wash-strong` | 主操作 / 悬停和选中描边 / 强调底上的字 / 轻高亮 / 选中行 |
| 状态 | `--c-ok` / `--c-warn` / `--c-err` / `--c-info` | 成功 / 警告 / 错误 / 信息、链接 |
| 图层标签 | `--tag-*` | 智能对象状态：可编辑、内容格式、共享、独立、外链、AI |
| 同源分组色板 | `--lc-0`…`--lc-7` | `.c0`–`.c7`：图层色条、共享标签、智能对象标识，按顺序轮换 |
| 高亮文字 | `--c-text-hi` | 强调底、拖拽目标上的字；勾选标记 |

生图页沿用外置面板的内容顺序：提示词、收藏、参考图、目标状态、数量与主按钮；内置页不重复显示变体缩略图卡片，缩略图仍由独立 native 变体栏承载。顶部工作流栏、生成/工具切换和模式工具栏保持原样。

图层面板的行高（`--lt-row` 等）按缩略图档位切换，属于组件内部变量，保留在 `.lt-list` 上。

## 3. 组件规则

| 组件 | 规格 | 状态 |
|---|---|---|
| 按钮 | 高 `--h-m`，左右 `--sp-4`，`--r`，描边 `--c-line` | 悬停：`--c-hover` 底 + `--c-accent` 描边；禁用：`--op-disabled` |
| 主按钮（生成） | 高 `--h-l`，`--c-accent` 底，`--c-accent-ink` 字 | 悬停 `--c-accent-hi` |
| 生图数量行 | 重置按钮 `--h-xs`；整数框和生成按钮高 `--h-count`；滚轮每格增减 1，范围 1～4 | 与外置生图面板保持一致 |
| 图标按钮 | 方形，边长 `--h-s`（紧凑）或 `--h-m`，图标 `--ic-m` | 同按钮；切换开启时图标 `--c-accent-hi` |
| 输入框 / 搜索框 | 高 `--h-s`（面板顶部）或 `--h-m`，`--c-field` 底；搜索框**不撑满**，与筛选图标同行 | 聚焦 `--c-accent` 描边 |
| 下拉框 | 同输入框高度，右侧箭头 `--ic-s` | |
| 胶囊（工作流、连接） | 高 `--h-m`，`--r-pill` | |
| 标签 | 高 `--h-xs`，`--fs-s`，左右 `--sp-2`，`--r` | 颜色只用 `--tag-*` |
| 列表行 | 行线 `--c-line-row`；选中 `--c-accent-wash-strong` | 拖拽目标 `--c-accent-hi` 2px 描边 |
| 分区 | `--c-surface` 底，`--r`，内边距 `--sp-4` | |
| 提示条 | 左侧 2px 状态色，`--fs-s` | warn / err |
| 菜单 | 行高 `--h-m`，左右 `--sp-3` | 悬停 `--c-hover` |
| 图层拖拽虚影 | 高 `--h-drag`，缩略图 `--h-m`，半透明底色，显示图层名和当前放置动作 | 目标槽位用 `--c-accent-hi` 高亮；不接管键盘或鼠标 |

图层面板的 PS 含义图标（眼睛、锁定、链接、蒙版、调整、图层组、新建、删除、图层类型、智能滤镜、剪贴、共用 / 独立 / 外链、矢量蒙版、可编辑 / 不可编辑）用 `dom.ts` 的 `PS_GLYPHS`：20×20 实心图形、单条 even-odd 路径，照 PS 原版图层面板截图画（11-04）。**全部单色**（`--c-text-2`），颜色只留给提醒：不可编辑（珊瑚色）、AI、共用分组色 `--lc-*`。主面板其余图标仍是线性风格（描边 1.5）。

## 4. UXP 限制（设计时就要遵守）

- 变量引用变量（`--muted: var(--c-text-2)`）在 UXP 里可用（11-04 在 PS 实测，外观不变）。
- **不画 `box-shadow`**：浮层、拖拽态用描边和底色区分。
- `<button>`、`<label>` 会渲染成原生控件，用 `h()` 生成的 div。
- 原生 `input[type=range]` 和数字输入框很高，用自绘的 `slider.ts`。
- `title` 不显示，用 `tooltip.ts`。
- CSS 属性选择器不可靠，状态用 class（`.on`、`.is-disabled`、`.hot`）。
- 细长图片、原生滚动区可能让面板停止绘制，缩略图比例限制在 4:1 以内。
- `gap` 的支持情况需要确认：`styles.css` 开头的注释写着「不用 gap」，但现在有 11 处用了 `gap`。

## 6. 开发期规则（现在就执行）

1. 新写的 CSS 用 `--c-*`、`--sp-*`、`--h-*` 等新 token（旧名 `--text`、`--muted` 等仍可用），不新增写死的颜色。
2. 新的数值尽量从 token 表里选：字号不小于 11px，间距和控件高度用第 2 节的档位。
3. 有现成组件或 class 就复用，不要为一个功能单独写一套按钮或输入框。
4. 用户明确提过的 UI 要求，补进本文件第 3 节。

## 8. 已定的决策（2026-11-04，用户授权 AI 决定）

- **最小字号 11px**：现有 10px / 9px 的文字（变体数量、工作台条目、提示）迁移时统一改成 11px。区域放不下时，先缩短文字或改成悬停提示，不能回退到 10px。
- **只支持 PS 深色和中灰主题**：浅色主题暂不适配。颜色都已经集中在 token 里，以后需要时只要在 `styles.css` 的 token 区加一组 `@media (prefers-color-scheme: light)` 覆盖，组件不用改。
- **控件高度用 24 / 26 两档**：图层面板顶部（筛选、搜索、图标、锁定行）统一用 24，主面板的输入框、下拉框、按钮统一用 26，标签用 18，主按钮用 30。原定紧凑档 22，11-04 改为 24：搜索框和混合模式是 UXP 原生输入框 / 下拉框，低于 24 容易裁字，24 也是 Spectrum 紧凑控件的尺寸。

## 9. Native 拖拽预览卡片

- 固定视口尺寸：232×68 logical px；Win32 窗口按当前显示器 DPI 缩放，鼠标始终对应卡片中心。
- 单一圆角 surface（7px）和单描边；不使用黑色背板、重复描边或阴影。
- 缩略图固定 40×40，保持原图比例；图层名称 13px 粗体，超长单行省略。
- 操作状态使用小型胶囊标签和状态点：移动青绿、复制橙黄、删除红色、工作台蓝色、不可用中性灰；卡片外框保持中性，不整张染色。
- 多图层仅显示最多 4 层轻微错位的后置卡片；偏移只作为视觉效果，不改变鼠标跟随位置和投放命中。
