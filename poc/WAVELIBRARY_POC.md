# WaveLibrary POC 结果

对应 [`docs/WAVELIBRARY_SPEC.md`](../docs/WAVELIBRARY_SPEC.md) 第 13 节。

## 环境

- 2026-11-17，主机 Photoshop 27.10.0（Windows），通过 Photoshop MCP 执行 ExtendScript（`executeAction` 描述符，和 UXP `batchPlay` 是同一套命令）。**不是在 WavePlug 插件里跑的**，第 3 项还要在插件里复核一次。
- 测试文件在主机 `F:\WaveLibrary_POC\p0\`（本地 NTFS 盘）：
  - `A.png`、`B.png`：800×600，四色块 + 左上黑色标记（内容不同，尺寸相同）。
  - `C_2x.png`：1600×1200，内容同 A。
  - `p0_test.psd`：2000×1500，背景 + 灰色 `base` + 嵌入智能对象 `SO`（A.png）。
  - `before.png`、`after1.png`、`after4.png`：合成画面，用于逐像素比对。
- `SO` 带全部要检查的属性：缩放 60%、旋转 15°、平移、变形（warp）、智能滤镜（高斯模糊 2px）、正片叠底、不透明度 70%、投影 + 描边、像素蒙版、矢量蒙版、剪贴到 `base`。
- 像素比对方法：两张合成图做「差值」混合后看直方图，`maxDiff` 是任一通道的最大差值。

## P0-1 嵌入转链接：通过

```js
// 必须同时给目标图层和保存路径；只给路径会报「命令"转换为链接对象"当前不可用」
{ _obj: "placedLayerConvertToLinked",
  _target: [{ _ref: "layer", _enum: "ordinal", _value: "targetEnum" }],
  using: { _path: token, _kind: "local" } }
```

- 写出了 `WaveLibrary\asset_001_A\source.png`，图层变成链接，链接指向这个文件。
- 名称、混合模式、不透明度、剪贴、像素蒙版、矢量蒙版、图层样式、智能滤镜、变换四角坐标、变形全部不变。
- 合成画面转换前后逐像素比对：`maxDiff = 0`。
- 一步历史记录「将智能对象转换为链接对象」。
- 智能对象的内部 ID（`smartObjectMore.ID`）会变成新的。
- 另一种做法也可行：对**嵌入**对象直接执行 `placedLayerRelinkToFile`，它就变成链接到那个文件的链接对象（见 P0-2 c）。

## P0-2 复制图层与重新链接：**部分不通过**，需要改设计

| 测试 | 结果 |
|---|---|
| a. 链接图层 Ctrl+J 复制，重新链接副本 | 原图层**跟着变** |
| b. 嵌入图层复制（两者共享内容），把其中一个转为链接 | **只有这一个**变成链接，另一个仍是嵌入 |
| c. 对嵌入图层直接重新链接到另一个图层正在用的文件 | 可以，两者链接同一个文件 |
| d. 接 c，重新链接其中一个 | 另一个**跟着变** |
| e. 链接图层上执行「通过拷贝新建智能对象」 | 不可用（命令当前不可用） |
| f. 两个分别置入、原本无关的图层，先后重新链接到同一个文件，再改其中一个 | 另一个**跟着变**，之后一直绑在一起 |
| g. 两个图层分别链接 `source.png` 和它的 NTFS 硬链接 `source_hardlink.png`（同一份数据，不同路径） | **互相独立** |
| h. 嵌入其中一个（`placedLayerConvertToEmbedded`） | 同组的**全部**变成嵌入 |
| i. 接 h，在其中一个上执行「通过拷贝新建智能对象」，再把副本重新链接到另一个路径 | 副本**独立**，原来那组不受影响；副本保留变换、变形、蒙版、样式、智能滤镜，但**丢了剪贴蒙版**（要重新设置） |

结论：

- **Photoshop 按文件路径把链接图层分组。** 链接同一个路径的图层，重新链接其中任何一个，全部跟着变，而且一旦链接到同一路径就一直绑在一起。
- 所以「同一资产的两个图层各用各的变体」只在两者**链接不同路径**时成立。只要有一刻两个图层用了同一个变体文件，它们就会被绑定。
- 可行的绕过办法：同一份数据给不同图层不同的路径（硬链接，g 已验证；不支持硬链接的盘就复制一份）。
- 已经绑定的图层，要拆开只能走 h + i：整组先嵌入，复制出一个独立副本，再链接回去。大文件时很慢，副本是新图层（ID 变了），剪贴蒙版要补设。

对 6.3「只转换这一个」的影响是好消息：嵌入的复制图层可以一个一个单独转（b），不需要先「通过拷贝新建智能对象」。「全部转换」做法：转换其中一个，再把其余几个重新链接到同一个文件（c）。

## P0-3 撤销与历史记录：通过（插件里待复核）

- 连续 5 次重新链接后，在历史记录里往回跳 1、2、3 步再跳回最新：每一步每个图层的链接路径都准确回到当时的状态，`executeActionGet` 立刻读到新路径。
- `executeAction("undo")` 也能撤销，但它是「还原 / 重做」切换，连续调用第二次报「还原当前不可用」。插件里用历史记录状态跳转更可靠。
- 要在插件里复核：UXP 里读到的路径是否同样立刻更新，以及能否收到历史变化事件来刷新变体栏。

## P0-4 同尺寸重新链接：通过

- 在 A.png、B.png、`source.png` 之间重新链接多次，变换四角坐标始终是 `[914.77, 564.02, 1378.41, 688.25, 1285.23, 1035.98, 821.59, 911.75]`，一位小数都没变。
- 隐藏其他图层后，和转换前的合成画面逐像素比对：`maxDiff = 0`。

## 顺带看到的（P1-5 预备）

- 重新链接到 2 倍大的 `C_2x.png`：Photoshop 保留**缩放百分比**，图层在画布上以中心为基准**放大成 2 倍**（四角 `[729.53, 328.03, 1656.82, 576.5, …]`）。所以放大当前图层时，新图层要再缩小到 1 / 倍数才能和原图层重合。
- 链接回原尺寸文件后，四角坐标恢复原值。
