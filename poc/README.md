# P1 · 智能对象版本链 POC（2026-10-30，mainpc 实机）

执行方式：Photoshop 2026 (27.10.0) 中通过 ExtendScript Action Manager 运行 `so_lib.jsx`。
所用 Action 描述符与 UXP `batchPlay` 相同；UXP 侧还需在插件装好后复测一次。
只操作脚本新建的 `WavePlug_POC_*` 文档（有名称守卫），未触碰用户打开的 PSD。
结果文件：`SO_chain_POC_20261030.psd`。

## 流程

1. 新任务组：盖印可见 → 按选区外接矩形「通过拷贝的图层」（不经过剪贴板）→ 图层命名 `WavePlug_<任务ID>` → 转为智能对象 → 用羽化选区给 SO 加图层蒙版。
   内嵌文件名 = `WavePlug_T1.psb`，主文档不打开 PSB 即可从 `smartObject.fileReference` 读到 → 用作任务组身份。
2. 追加版本：`placedLayerEditContents` 打开 PSB（核对文件名）→ `Plc ` 置入结果 PNG → 缩放到 PSB 画布 → 栅格化 → 命名 `00N` → 逐个版本「独显 + 重新记录/新建 Layer Comp」→ 只显示新版本 → 计数器写入 PSB 文件信息 → 保存关闭 → 主文档 `setPlacedLayerComp` 切到新版本。
3. 切换：主文档对 SO 执行 `setPlacedLayerComp`，不打开 PSB。

## 结论与设计要点

- 核心链路在真实 Photoshop 中完全可行。
- **孤儿复合**：用户手删图层后，主文档看到的复合列表不会自动更新。方案：插件监听 PSB 的保存事件（文档名匹配 `WavePlug_*.psb`），在 PSB 仍打开时重建复合并再保存；兜底在下次追加时同步。历史栏也可对「找不到图层」的复合做标记。
- 计数器目前写在 PSB 的「文件简介 → 说明」字段（XMP），随 PSD 复制而走。UXP 侧需确认可读写（备选：`XMPMetadataAsUTF8`）。
- 首次建组用盖印 + 通过拷贝的图层，单图层文档跳过盖印（盖印命令要求 ≥2 个可见图层）。
- 打开 PSB 时会短暂出现文档标签页，属于预期。
