# WavePlug 浮动生成条（原型 0.1）

> 接手开发先读 [`HANDOFF.md`](HANDOFF.md)。

在 PS 里画完选区、松开鼠标，鼠标旁边弹出一条小窗口：**提示词 · 数量 · 生成**。它在插件面板外面，所以不受 UXP 面板边界限制。

```
[ 提示词……………………… ] [ 1 ] [ 生成 ] ×
```

## 怎么用

1. **编译**（只需一次，在 Windows 主机上）：
   - 安装 Rust：<https://rustup.rs>，按提示装 Visual Studio Build Tools（C++ 生成工具）。
   - 双击 `build.cmd`。成功后得到 `dist\waveplug-overlay.exe`；它会先结束正在运行的旧版本，编译完自动启动新版本。
2. **运行**：双击 `waveplug-overlay.exe`。没有窗口、没有托盘图标，在后台等插件连接。再双击一次不会开第二个。
3. 在 PS 开发版面板点 ⟳。日志（`reports/uxp_runtime.log`）里出现 `overlay connected` 就连上了。
4. 在局部重绘 / 融图 / 抠图 / 文生图模式下画一个选区：鼠标旁边弹出生成条，提示词是面板里当前的提示词。

## 操作

| 操作 | 结果 |
|---|---|
| 建立选区（任何方式：框选、套索、全选、Ctrl+单击缩略图） | 在**选区正下方居中**弹出，和选区底边的距离固定，与 PS 自带的上下文任务栏同一位置（下方放不下时在选区上方） |
| 在 PS 画面上再按下鼠标（开始画下一个选区） | 立即收起，画完在新位置重新弹出 |
| 弹出后继续在 PS 里操作 | 生成条**不抢焦点**，PS 快捷键照常用 |
| 点提示词框 | 选中原有提示词，可以直接输入替换，中文输入法正常 |
| Enter 或「生成」 | 把提示词和数量交给面板生成（等同在面板里点生成），生成条收起，焦点回到 PS |
| Esc 或 × | 收起，焦点回到 PS |
| 取消选区（Ctrl+D） | 收起 |
| 切到别的程序 | 收起 |
| 拖生成条的空白边缘 | 移动它 |

数量、提示词会同步回面板。扩图和放大模式不弹（它们不用选区）。面板正在生成时也不弹。

## 退出

原型还没有托盘图标：在任务管理器里结束 `waveplug-overlay.exe`。不运行它时插件和以前完全一样。

## 实现

- 纯 Win32（`windows-sys`），中文输入法和普通 Windows 输入框一样可靠；颜色取自 `styles.css` 的 token。
- 和插件通过 `ws://127.0.0.1:47821` 通信（只监听本机）。消息格式见 `src/protocol.rs` 和插件的 `src/core/overlay/protocol.ts`，两边要一起改。
- 位置：插件读 PS 文档的 `zoom`、`center`（视图中心对应的文档点，单位是点）、`resolution` 和 `viewInfo.activeView.globalBounds`（画布视图在屏幕上的范围），把选区换算成屏幕坐标发给小程序（`docToScreen`，`src/core/overlay/protocol.ts`）。读不到时退回到低级鼠标钩子记录的最近一次拖动范围，再不行退回鼠标位置。日志里每次弹出都有一行 `overlay show`，记着选区、视图和算出的屏幕位置。
- 按显示器 DPI 缩放；Windows 11 上是圆角。
- 插件端：`src/app/overlay.ts` 连接，断开后每 3 秒重试；`src/ui/app.ts` 的 `syncOverlay` / `onOverlay` 决定何时弹出、收到生成后做什么。
