# WavePlug 外附介面（0.2）

> 接手开发先读 [`HANDOFF.md`](HANDOFF.md)：架构、协议、怎么新增一个外附介面。

UXP 插件面板里的东西画不出面板边界。这个 Windows 小程序和插件通过本机 WebSocket 通信，在面板外面显示插件的界面（外附介面）。现在只有一个：**外置生成面板**——Photoshop 文档有选区时出现在画布右下角，内容和插件的生成页一样。

## 怎么用

1. **编译**（Windows 主机）：装好 Rust（<https://rustup.rs>，按提示装 Visual Studio C++ 生成工具），双击 `build.cmd`。它先跑测试，再编译，结束正在运行的旧版本，复制到 `dist\waveplug-overlay.exe` 并启动新版本。
2. **插件**：在 PS 开发版面板点 ⟳。日志 `reports/uxp_runtime.log` 里出现 `overlay connected` / `overlay ready 0.2.0` 就连上了。
3. 在 PS 里画一个选区：画布右下角出现外置生成面板；取消选区就消失。

小程序没有窗口、没有托盘图标，平时在后台等插件；再双击一次不会开第二个。不运行它时插件和以前完全一样。退出：任务管理器结束 `waveplug-overlay.exe`。

## 不连 PS 试界面

- **Demo**：双击 `demo.cmd`（= `waveplug-overlay.exe --demo`），假数据，可以随便点。底部「仅 Demo」一行可以模拟有没有选区。
- **假插件**：先运行 `waveplug-overlay.exe`，再在项目根目录运行 `node native/overlay/tools/fake_plugin.ts`。它用插件真正的通信代码（`src/core/overlay/hub.ts`）发一份状态并让面板显示，打印面板发回来的操作。在 Mac 上也能跑（面板不隐藏，方便看）。
- **截图自检**：给 Demo 设环境变量 `WAVEPLUG_DEMO_SHOT=<文件.bmp>`（可加 `WAVEPLUG_DEMO_OPEN=sel,adv,fav,ref,prompt,run`），给主程序设 `WAVEPLUG_HOST_SHOT=<文件.bmp>`：画几帧后存一张窗口截图并退出。

## 资源占用

外置程序自己的日志：`reports/overlay_runtime.log`（谁拿着键盘、面板放在哪里），排查快捷键等问题时先看它。

界面用 egui（原生绘制，没有浏览器内核）。中文字体直接用系统的微软雅黑，按需读取、不整份读进内存。Mac 上实测约 35 MB；Windows 待实测。隐藏时不占 CPU。
